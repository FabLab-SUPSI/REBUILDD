# Material Passport Workshop Repository

This repository hosts the **material passport** for the workshop: a structured record of materials, components, sources, properties, and reuse pathways collected during the project.

## Purpose

The goal of this repository is to document the workshop’s material research in a clear, reusable, and shareable format. It is intended to support:

- **Material tracing**
- **Circular design**
- **Reuse and recovery**
- **Documentation for future projects**
- **Knowledge sharing across the workshop team**

## What is a material passport?

A material passport is a dataset or document that describes a material or product in enough detail to support future use, maintenance, disassembly, repair, reuse, or recycling. In this repository, the passport will be used as a living archive of the workshop’s material choices and outcomes.

## Repository contents

This repository may include:

- Material inventory sheets
- Product and supplier information
- Technical specifications
- Photos and diagrams
- Environmental or circularity notes
- Disassembly and reuse instructions
- Workshop documentation and references

Use descriptive, consistent file names such as:

Example:
material-passport_plywood_prototype-a_2026-08-24.md
Recommended passport fields
Each material passport should ideally include:

Category
Source / supplier
Manufacturer
Dimensions / quantity
Composition
Condition
Assembly method
Disassembly notes

Documentation links or files

## Contributing
When adding or editing material passports:

- Keep information accurate and verifiable.
- Use a consistent format across entries.
- Add images or sketches when useful.
- Note any unknown or missing data explicitly.
